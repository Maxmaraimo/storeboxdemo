# StoreBox Uzbekistan — SaaS Платформа Интернет-магазинов и Telegram Mini App (TMA)

Локальная мультиарендная (multi-tenant) SaaS-платформа для быстрого запуска интернет-магазинов и Telegram-витрин в Узбекистане (аналог StoreBox / StoreBox).

---

## 🚀 Возможности платформы

1. **Мультиарендность (Multi-tenancy на поддоменах):**
   - Разделение магазинов по поддоменам (`mystore.platform.uz`, `mystore.localhost:8000`) или через префикс `/store/<subdomain>/`.
   - Полная изоляция данных на уровне Django ORM (`SubdomainTenantMiddleware`).
   - Кастомный брендинг для каждого магазина (логотип, баннер, фирменный цвет бренда).

2. **Telegram Mini App (TMA) и Telegram-бот:**
   - Полноценная витрина внутри Telegram с поддержкой `Telegram.WebApp` SDK.
   - Авто-подстановка имени и Telegram ID пользователя.
   - Моментальные уведомления в Telegram-группу мерчанта при оформлении или оплате заказа с подробным чеком.

3. **Локальные платежные системы Узбекистана:**
   - **Click Shop API:** Двухфазная оплата (`/payments/click/prepare/`, `/payments/click/complete/`) с проверкой MD5-подписи.
   - **Payme Merchant API:** Протокол JSON-RPC 2.0 (`/payments/payme/`) с методами `CheckPerformTransaction`, `CreateTransaction`, `PerformTransaction`, `CancelTransaction`.
   - **Uzum Pay:** Вебхук для мгновенного подтверждения оплаты.
   - **Интерактивный симулятор оплат:** Оплата в 1 клик для демонстраций и тестирования без банковского договора.
   - Оплата наличными или картой (терминал) при получении.

4. **Вариации товаров и складской учет:**
   - Вариации (Размеры: S/M/L, вкусы, цвета) с индивидуальными ценами и остатками.
   - Автоматическое списание остатка при заказе.
   - Бейджи «Скидка -X%», «Хит», «Нет в наличии».

5. **Маркетинг и промокоды:**
   - Промокоды на процентную скидку (%) или фиксированную сумму в сумах (UZS).
   - Лимиты использований и минимальная сумма заказа.

6. **Управление доставкой:**
   - Курьерская доставка с авто-расчетом бесплатной доставки от суммы (например, бесплатно от 150 000 UZS).
   - Самовывоз из магазина.

7. **Мультиязычность:**
   - Поддержка интерфейса и карточек товаров на узбекском (UZ) и русском (RU) языках.

## 🛠 Быстрый старт и запуск

### 1. Установка зависимостей
```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

### 2. Применение миграций
```bash
python manage.py migrate
```

### 3. Загрузка демонстрационного магазина «Gold Lavash»
```bash
python manage.py setup_demo_store
```

### 4. Запуск сервера разработки
```bash
python manage.py runserver 0.0.0.0:8000
```
